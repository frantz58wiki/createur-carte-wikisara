Aide

1. Importer des données

Collez vos données dans la zone d'importation puis utilisez le bouton 📥 Importer les lignes / points.

Les points uniques sont placés avant |lines=. Ils sont reconnus lorsqu'ils comportent une latitude et une longitude suivies de ~ et du texte du point.

Les lignes sont placées après |lines=. Les coordonnées successives d'une ligne sont séparées par :.

Le ; peut séparer les éléments et peut être absent à la fin du dernier élément.

2. Choisir une couche de données pour le fond de plan

Utilisez le sélecteur de fond de plan pour choisir la couche cartographique affichée derrière vos points et vos lignes.

3. Fonctions des boutons

  • Pour créer une ligne, appuyer sur le bouton Ajout ligne. Cela permet de créer une ligne par point successif, lorsque vous voulez arrêter la création de la ligne, il faut cliquer sur le bouton Ajout ligne ou cliquer sur le bouton ⏹️ Terminer ligne. Après avoir fait cela, vous ne pouvez plus modifier les paramètres de la ligne à moins de passer par le bouton ✏️ Édition. Vous pouvez déplacer un point unique ou un point d'une ligne en restant appuyé sur le clic gauche une fois au-dessus du point. Un clic droit au-dessus d'un point unique ou d'un point d'une ligne supprimera ce dernier.
  • Insertion : Permet d'insérer des points sur une ligne existante.
  • 🗑️ Suppression : Permet de supprimer une ligne ou un point.
  • ✏️ Édition : Permet d'éditer un point unique ou les paramètres d'une ligne.
  • 📍 Point unique : Permet de créer un point unique.
  • ⏹️ Terminer ligne : Permet d'arrêter une ligne en cours de création.
  • ➡️ Flèches : Permet d'afficher le sens de la ligne.
  • ➕ Prolonger ligne : Permet de prolonger une ligne ; la ligne sera prolongée par l'extrémité la plus proche du point cliqué sur la ligne.
  • 🔄 Inverser sens ligne : Inverse le sens d'une ligne.
  • 🗑️ Supprimer points : Permet de supprimer un point unique ou un point d'une ligne via le clic droit.
  • ✂️ Couper ligne : Coupe une ligne au niveau du clic.
  • 🔗 Fusionner lignes : Ce bouton permet de réunir deux lignes en reprenant les paramètres de la première ligne cliquée. La jonction entre les deux lignes se fera par leurs extrémités les plus proches.
  • 🛣️ Itinéraire routier : Permet de choisir deux points, puis d'ajouter autant de points d'étape que nécessaire pour forcer le parcours à suivre les routes souhaitées. Le calcul ignore les sens uniques. Une fois l'itinéraire satisfaisant, choisissez les paramètres de la ligne avant son intégration aux données.
  • 📥 Importer les lignes / points : Ce bouton permet d'importer des points et des lignes (voir plus de détails en haut de la fenêtre d'aide.
  • 🧹 Effacer tout : Ce bouton permet de remettre à zéro tout.
  • ↩️ Annuler : Ce bouton permet d'annuler l'action précédente (jusqu'à 100 actions annulables).
  • Export Wikisara : Ce bouton permet d'exporter les données directement sous la forme attendue par Wikisara, pour que cela apparaisse dans les articles. Si vous préférez extraire qu'une partie des données, il est préférable de récupérer les données brutes dans la fenêtre qui s'affiche entre la carte et les boutons de sélection de fond de plan.

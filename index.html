❓ Aide

📥 Importer les lignes / points

Collez vos données dans la zone de texte puis cliquez sur 📥 Importer les lignes / points. L'import reconnaît les points uniques et les lignes, y compris lorsque les coordonnées sont écrites avec ou sans espace après la virgule.

Pour les points uniques, la reconnaissance repose notamment sur la présence d'une latitude et d'une longitude avant le séparateur ~. Le ; final peut être présent ou absent. Les appels de modèle, lorsqu'ils sont présents dans la partie des coordonnées des lignes, sont également conservés comme données de modèle.

Les données importées peuvent ensuite être triées avec 🔀 Tri des données avant d'être réexportées.

🗺️ Fonds de plan

Les boutons de fond de plan permettent de choisir le fond cartographique affiché sous vos données : fonds IGN, photographie aérienne, cartes historiques, cadastre et LIDAR MNT selon les options disponibles.

🌍 Hybride IGN permet de combiner les informations cartographiques et l'imagerie aérienne. Lorsqu'un réglage d'opacité est proposé, il permet de doser la visibilité du fond associé.

🛠️ Boutons de fonctions ON / OFF

Les boutons de cette famille passent en vert lorsqu'ils sont actifs (ON) et en rouge lorsqu'ils sont inactifs (OFF). Les outils de mode sont exclusifs : activer un autre mode désactive le précédent. Les boutons d'affichage et d'accrochage peuvent, eux, fonctionner comme des interrupteurs indépendants.

✏️ Ajout ligne

Active la création d'une nouvelle ligne. Cliquez successivement sur la carte pour placer ses points. La ligne en cours peut être terminée avec le bouton de fin de ligne lorsqu'il apparaît, ou en cliquant de nouveau sur l'outil selon le fonctionnement prévu par l'éditeur.

Si 🧲 Accrochage point est actif, un point créé suffisamment près d'un point existant peut s'y accrocher automatiquement.

➕ Insertion

Permet d'ajouter un point à une ligne existante. Sélectionnez d'abord la ligne par un clic, puis cliquez à l'endroit souhaité pour insérer le nouveau sommet dans la géométrie.

L'insertion est particulièrement utile pour ajouter de la précision localement sans recréer la ligne.

🗑️ Suppression

Permet de supprimer une ligne ou un élément sélectionné selon l'action effectuée. Utilisez un clic sur l'élément à supprimer ; les opérations de suppression sont enregistrées dans l'historique et peuvent donc être annulées.

✏️ Édition

Permet de sélectionner une ligne, un point unique ou une forme afin d'en modifier les paramètres disponibles. Pour une ligne, le clic sert à la sélectionner ; ses paramètres de texte, couleur et épaisseur peuvent alors être modifiés.

Pour un point unique, le clic gauche en mode Édition ouvre sa fenêtre de modification.

📍 Point unique

Active la création d'un point indépendant des lignes. Cliquez sur la carte pour placer le point, puis renseignez son texte lorsque la fenêtre de saisie apparaît.

Un point unique reste indépendant de la géométrie des lignes et reste visible quel que soit le niveau de zoom.

🔷 Ajouter forme

Active la création d'une forme géométrique. Cliquez successivement sur la carte pour définir les sommets, puis utilisez 🔷 Valider la forme géométrique lorsque la géométrie est terminée. Une fenêtre permet ensuite de renseigner les paramètres de la forme : textes, couleur et opacités du contour et du fond.

🧲 Accrochage point

Lorsque l'outil est ON, un point créé ou déplacé s'accroche au point existant le plus proche lorsqu'il se trouve à 150 m ou moins.

L'accrochage peut être utilisé lors de la création d'une ligne, lors de la création d'un point unique ou lors du déplacement d'un point. Après un accrochage réussi, l'outil se désactive automatiquement. S'il n'y a aucun point admissible à proximité, il reste actif.

➡️ Flèches

Affiche ou masque les flèches indiquant le sens de parcours des lignes. Les flèches apparaissent à partir du niveau de zoom prévu par l'éditeur. Le bouton peut être laissé sur ON ou OFF indépendamment des outils de modification.

🏷️ Textes lignes

Affiche ou masque les textes associés aux lignes. Le bouton agit uniquement sur leur affichage : il ne supprime pas les textes enregistrés dans les données de la ligne.

➕ Prolonger ligne

Permet de prolonger une ligne existante. Cliquez sur la ligne pour la sélectionner et déterminer le côté à prolonger, puis cliquez successivement sur la carte pour ajouter les nouveaux points à l'extrémité choisie.

🔄 Inverser sens ligne

Inverse l'ordre des points d'une ligne. La géométrie reste au même endroit, mais son sens est inversé. Cette fonction est notamment utile lorsque les flèches montrent un sens contraire à celui souhaité.

🗑️ Supprimer points

Permet de supprimer des sommets d'une ligne. Cliquez sur les points de ligne à supprimer. La ligne est reconstruite avec les points restants.

✂️ Couper ligne

Permet de couper une ligne en deux. Cliquez d'abord sur la ligne à couper pour la sélectionner, puis cliquez à l'endroit exact de la coupure.

Si le clic de coupure est situé à 150 m ou moins d'un point existant de la ligne, la coupure utilise automatiquement ce point. Il est donc possible de couper précisément sur un sommet sans devoir viser exactement son centre.

Lorsque le mode est actif, un clic sur un point de ligne est réservé à la coupure : le point ne peut pas être déplacé et le clic droit ne le supprime pas.

🔗 Fusionner lignes

Permet de réunir deux lignes. Cliquez sur la première ligne, puis sur la deuxième. L'éditeur recherche automatiquement l'orientation des deux lignes qui permet de relier les extrémités les plus proches. Si deux extrémités sont exactement superposées, le doublon de jonction est évité.

〽️ Simplifier tracé

Active un mode de sélection. Cliquez directement sur la ligne que vous souhaitez simplifier : elle est sélectionnée puis simplifiée automatiquement.

La simplification utilise le même procédé que celui utilisé pour les tracés issus de l'itinéraire routier : algorithme de Douglas-Peucker/RDP avec une tolérance de 5 mètres. Le nombre de points est ainsi réduit tout en conservant la forme générale du tracé.

Après une simplification réussie, le bouton repasse automatiquement sur OFF. Si l'opération ne peut pas être effectuée, le mode reste actif afin de permettre la sélection d'une autre ligne.

🛣️ Itinéraire routier

🛣️ Itinéraire routier calcule automatiquement un trajet routier entre des points choisis sur la carte.

1. Activez l'outil, puis cliquez sur le départ et sur l'arrivée.

2. Une prévisualisation de l'itinéraire est calculée. Vous pouvez ajouter des points de passage en cliquant sur la carte afin d'imposer au calcul des passages intermédiaires.

3. Chaque point de passage intermédiaire peut être déplacé ou supprimé avec les actions prévues autour de son marqueur.

4. Lorsque le tracé convient, utilisez Valider pour ouvrir le paramétrage de la ligne et l'intégrer à la carte.

Le tracé routier obtenu est automatiquement simplifié avec la même méthode RDP à 5 m de tolérance que celle utilisée par 〽️ Simplifier tracé.

📍 Réactions des points de ligne

Les points de ligne sont les petits marqueurs placés sur les sommets d'une ligne. Ils n'apparaissent que lorsque le niveau de zoom atteint le seuil choisi avec le curseur « Points des lignes : zoom », sauf lorsqu'une sélection ou une opération impose leur affichage.

  • Clic gauche court, mode normal : le point ne déclenche pas d'action de suppression ou d'édition par lui-même ; son comportement dépend du mode actif.
  • Clic gauche court en mode Édition : le point est traité comme un point de la ligne sélectionnée selon les fonctions d'édition disponibles.
  • Clic gauche court en mode Supprimer points : le point est supprimé de la ligne.
  • Clic gauche court en mode Couper ligne : le point sert de point de coupure ; il ne peut pas être déplacé.
  • Clic gauche maintenu + déplacement : le point peut être déplacé, ce qui déplace le sommet correspondant de la ligne. Le relâchement termine le déplacement et les données sont mises à jour.
  • Clic droit : le point est supprimé de la ligne dans le fonctionnement normal.
  • Clic droit en mode Couper ligne : aucune suppression n'est effectuée ; le point est réservé à l'opération de coupure.

Important : lorsqu'un outil comme Couper ligne réserve le point à une opération particulière, cette règle est prioritaire sur le comportement normal du marqueur.

📍 Réactions des points uniques

  • Clic gauche court en mode Édition : ouvre la fenêtre permettant de modifier le point unique et son texte.
  • Clic gauche court en mode Suppression : supprime le point unique.
  • Clic gauche court dans les autres modes : le clic n'ouvre pas la fenêtre d'édition du point ; son traitement dépend du mode actif, notamment de l'accrochage lorsqu'il est activé.
  • Clic gauche maintenu + déplacement : déplace le point unique. Lors du déplacement, son éventuel texte associé suit le point.
  • Clic droit court ou long : supprime le point unique. Le clic droit est intercepté afin d'empêcher le menu contextuel du navigateur de prendre le dessus.

Lorsqu'un point unique est déplacé avec 🧲 Accrochage point actif, il peut s'accrocher automatiquement à un point existant situé à 150 m ou moins.

🔀 Tri des données

Le bouton 🔀 Tri des données ouvre une fenêtre permettant de préparer et réorganiser les données avant leur utilisation ou leur export.

  • Tri des lignes — Par ordre de création : conserve l'ordre dans lequel les lignes ont été créées/importées.
  • Tri des lignes — Par couleur de ligne : regroupe les lignes par couleur. La fenêtre permet de définir l'ordre des groupes de couleurs.
  • Espace après la virgule — Avec espace : écrit les coordonnées sous la forme 48.123456, 2.123456.
  • Espace après la virgule — Sans espace : écrit les coordonnées sous la forme 48.123456,2.123456.
  • Zéros inutiles après la virgule — Conserver : conserve les zéros non significatifs présents dans les données.
  • Zéros inutiles après la virgule — Enlever : retire les zéros inutiles après la virgule.
  • Sauts de ligne supplémentaires — Conserver : conserve les sauts de ligne supplémentaires présents dans les données.
  • Sauts de ligne supplémentaires — Supprimer : retire les sauts de ligne qui ne sont pas nécessaires.

Une fois les options choisies, cliquez sur Valider pour appliquer le tri et la mise en forme. Annuler ferme la fenêtre sans appliquer ces réglages.

↩️ Annuler / ↪️ Rétablir

↩️ Annuler revient en arrière sur les dernières modifications. ↪️ Rétablir restaure une action précédemment annulée.

L'historique permet de revenir sur de nombreuses opérations de création et de modification. Une nouvelle modification après une annulation peut supprimer la possibilité de rétablir les actions annulées qui ne sont plus dans la branche active.

🧹 Effacer tout

🧹 Effacer tout supprime les données présentes sur la carte. Comme les autres modifications prises en charge par l'historique, cette opération peut être annulée si elle a été enregistrée dans l'historique.

📤 Exports

Export Wikisara ouvre la préparation de l'export classique. Les lignes, points uniques et formes sont convertis dans le format attendu par Wikisara, avec les paramètres associés.

Export type modèle Wikisara prépare un export destiné à un modèle Wikisara, avec les différentes parties du modèle placées dans les blocs appropriés.

🎚️ Points des lignes : zoom

Le curseur règle le niveau de zoom à partir duquel les points des lignes deviennent visibles. Il peut être réglé entre 10 et 16. La valeur 13 est la valeur par défaut.

Sur un petit écran, le curseur se place automatiquement sous son texte afin de conserver une présentation lisible.

📥 Importer des lignes / points

Collez vos données dans la zone d'importation puis cliquez sur 📥 Importer les lignes / points.

Les coordonnées peuvent être écrites avec ou sans espace après la virgule. Le dernier élément peut également être écrit sans ; final.

Les données d'un modèle Wikisara contenant <includeonly> et <noinclude> sont également reconnues, sans supprimer la prise en charge des autres formats.

🗺️ Fonds de plan

Utilisez le sélecteur de fond de plan pour choisir la couche affichée sous vos données.

🌍 Hybride IGN permet de mélanger la carte et l'imagerie aérienne grâce au curseur d'opacité.

✏️ Outils de création et de modification

  • Ajout ligne : crée une ligne par clics successifs sur la carte. Cliquez de nouveau sur Ajout ligne pour terminer la création.
  • Insertion : permet d'insérer des points dans une ligne existante.
  • 🗑️ Suppression : permet de supprimer une ligne ou un point.
  • ✏️ Édition : permet de modifier les paramètres d'un élément existant.
  • 📍 Point unique : ajoute un point indépendant d'une ligne.
  • 🔷 Ajouter forme : active l'outil de création de forme. Cliquez sur la carte pour définir sa géométrie puis validez la forme.
  • ➡️ Flèches : affiche ou masque les flèches indiquant le sens des lignes.
  • ➕ Prolonger ligne : permet de prolonger une ligne.
  • 🔄 Inverser sens ligne : inverse le sens d'une ligne.
  • 🗑️ Supprimer points : permet de supprimer des points.
  • ✂️ Couper ligne : permet de couper une ligne.
  • 🔗 Fusionner lignes : permet de réunir deux lignes.

🧲 Accrochage point

Lorsque 🧲 Accrochage point est activé, un point créé ou déplacé s'accroche au point existant le plus proche s'il se trouve à moins de 150 m.

Après un accrochage réussi, l'outil se désactive automatiquement. S'il n'y a aucun point à moins de 150 m, il reste actif.

🛣️ Itinéraire routier

Activez 🛣️ Itinéraire routier, puis cliquez sur le point de départ et le point d'arrivée.

Une fois ces deux points déterminés, une fenêtre apparaît en bas au centre de la carte : « Ajouter des points de passage en cliquant sur la carte et/ou Valider ».

Ajoutez des points de passage en cliquant sur la carte. L'itinéraire est recalculé. Cliquez sur Valider lorsque le tracé convient afin d'ouvrir le paramétrage de la ligne.

↩️ Annuler

↩️ Annuler permet d'annuler les actions précédentes une par une. L'historique peut conserver jusqu'à 100 actions.

Le compteur indique le nombre d'actions actuellement disponibles.

🧹 Effacer et exporter

  • 🧹 Effacer tout : efface les données présentes sur la carte.
  • Export Wikisara : ouvre la fenêtre de préparation de l'export Wikisara.
  • Export type modèle Wikisara : ouvre la fenêtre de paramétrage de cet export. Le texte associé au modèle est placé entre <noinclude> et </noinclude>, tandis que les éléments exportés sont placés entre <includeonly> et </includeonly>.

    • Lorsqu'un seul objet est une forme, l'export utilise uniquement ses coordonnées, la couleur et l'épaisseur du contour ; l'opacité du contour, la couleur du fond et l'opacité du fond sont ignorées.

⚙️ Paramètres

Les lignes utilisent les paramètres Texte ligne 1, Texte ligne 2, Couleur et Épaisseur.

Les formes disposent de leurs paramètres propres. Une ligne terminée peut être modifiée avec ✏️ Édition.

Export type modèle Wikisara

Le contenu des lignes sera placé entre les balises <includeonly> et </includeonly>.

Texte associé au modèle : Ce texte sera placé entre les balises <noinclude> et </noinclude>.
